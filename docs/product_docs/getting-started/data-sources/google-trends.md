## What it is
**Search-interest curves** for homefront topics. Useful **early warning**, not primary scored evidence. Values are relative (0–100), not population counts.

## In the app
Open **Data sources** → **Trends**. Compare interest over time for configured topics.

## When to use it
- Spot rising public attention before it appears in news or groups
- Context only — always confirm with component evidence on the daily report

## Troubleshooting
- **Spike with no score change** — trends are not scored as primary evidence by design.
- **Demo or stale banner** — live fetch may be unavailable; read the tab status message.
