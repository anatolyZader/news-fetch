## What it is
Links, quotes, and short observations you paste in the top **Send data** bar. Reviewed and folded into the **next assessment run** when accepted.

## In the app
Use **Send data** in the top bar (not a Data sources tab). For full structured reports, use **Write report** instead → [Report bot](report-bot.md).

## When to use it
- Flag a URL or quote the automated feeds missed
- Add field context without filing a full bot report

## Troubleshooting
- **Nothing changed in today's report** — submissions apply to a **future** run after review.
- **Need a formal report** — use Write report or the WhatsApp bot for structured submissions.
